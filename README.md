# VOC Simulation (1602–1660)

Агентная симуляция экономики Голландской Республики и Ост-Индской компании
с советом директоров (Heeren XVII) в роли LLM-агентов.

## Состав проекта

- `voc_engine_v3.py` — движок симуляции: популяция, заработки, цена акций VOC,
  дивиденды, флот, долг, беспорядки, концентрация капитала у регентов.
- `monte_carlo.py` — калибровка параметров движка по историческим данным
  (4 200 прогонов: 150 сэмплов × 4 политических сценария × 7 политик компании).
- `voc_council.py` — совет из 17 «директоров» (Qwen 3 8B через Ollama):
  каждый голосует по дивидендам, войне и спуску кораблей, решение — медиана голосов.
- `mc_raw.csv` — сырые результаты калибровки; `metrics_*.csv` — годовые метрики прогонов;
  `council_log*.csv` — журнал решений совета по версиям экспериментов.

## Экспериментальная серия: совет директоров v1–v7

Каждая версия отличается контекстом, который видит совет, и институтами:

| Версия | Изменение | Режим | Финал 1660 |
|---|---|---|---|
| v1–v2 | якорь «LOW dividends» | скупость | крах: цена 10, unrest 9–12 |
| v3 | «плати при unrest > 2» | осторожность (флот 1–3) | крах: нет флота — нет выруч revenue |
| v4 | бюджетная арифметика | накопительство | крах: цена 10 |
| v5 | кредит на корабли | маятник 2↔16 кораблей | цена 52,5, долг 22,8 млн |
| v6 | ретроспектива мандата | стабильность, ноль выплат | цена 10, unrest 11,8 |
| v7 | + ревизия участников | равновесие: 2%, флот 12 | цена 159,9, долг 0 |

## Сравнение с калиброванной базой (1660)

| Прогон | Цена | Дивиденды, % капитала | Долг, млн | Unrest | Регенты, % |
|---|---|---|---|---|---|
| base (фикс. правило) | 368.5 | 413 | 0 | 0 | 46.5 |
| v7 (совет + ревизия) | 159.9 | 92 | 0 | 0 | 63.5 |

## Вывод

LLM-комитет без обратной связи вырождается в предельные режимы (скупость,
осторожность, накопительство, маятник). Ретроспектива мандата стабилизирует
флот, но дивидендную дисциплину восстанавливает только внешний институт —
давление участников (ревизия), аналогичное историческому бунту акционеров 1622 года.
Симуляция воспроизводит вывод исторической literature о механизмах подотчётности
Heeren XVII.
